# Equity2Bitcoin

Commercial marketing and conversion site for **Equity2Bitcoin Consulting LLC** — educational consulting that helps homeowners responsibly unlock home equity and reposition it into Bitcoin.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Local Vite dev server |
| `npm run build` | Typecheck + production build → `dist/` |
| `npm run preview` | Preview the production build |
| `npm run typecheck` | TypeScript only |
